# SignalPass 核心体验重设计

日期：2026-09-28。范围：原生 V4 首页、发现、写信，以及所有 V4 页面的共享账户区与部分阅读控件。

## 本轮交付

- 首页：明确面向寻找合作对象的人；突出一个发现入口。以标明示例的 Alex / Maya 介绍替代抽象关系图，提供共同背景、介绍草稿、对方选择三个可操作的面板。
- 发现：移除占据工作空间的大幅装饰，使用流式布局；扩大人物、兴趣与介绍理由，建立主次。实时目录为空时提供明确的示例入口，不自动混入示例用户。
- 写信：从固定缩放画布改为原生双栏布局；左侧宽幅编辑、右侧共享资料与审阅入口。保留原有草稿、共享上下文、确认、钱包和收件人决策逻辑。
- 共享账户区：移入现有导航，移除额外顶部栏。游客、示例、已登录和错误状态保留语义，缺少钱包时的错误仍可见。
- 阅读细节：提高编辑入口、上下文检查、费用说明等控件的可读性。收件人标签改为实际表达其兴趣，避免将兴趣误称为能力或已确认的共同点。
- 动效：保留有限的卡片反馈与接受状态印章，新增示例面板的短过渡；键盘、减少动态效果和隐藏页面的生命周期均检查。

## 关键测量

1440px 桌面：核心页面顶部从原先约 169–181px 的两层结构收敛到 84px；发现工作区从约 792px 扩展到 1328px；写信文本框从约 287px 扩展到约 708px。宽度反映本次视口，不代表所有设备。

## 验证

- pnpm v4:verify：页面、资源、资料编辑、隐私设置、草稿持久化、上下文同意、收件箱决定、Widget、空搜索、移动导航与键盘操作通过。
- pnpm motion:verify / motion:record：示例面板布局稳定、动画暂停、减少动态效果、卡片焦点、草稿计数、仅接受后印章，以及 16 组视口/路由检查通过。
- pnpm e2e：真实签名与会话、跨用户送达、权限、上下文交换、接受、服务重启恢复、真实与示例前端回归通过。
- CHAIN_TEST_MOTION=enabled pnpm chain:verify：本地 EVM 钱包切网、签名与锁定、取消、接受/拒绝/过期退款等断言通过；没有发送公开测试网交易。
- 钱包测试收尾曾出现浏览器关闭迟缓；改为先显式关闭浏览器上下文，再关闭浏览器，复跑后完整退出码为 0，记录在 chain-cleanup.log。
- pnpm build：生产构建通过。
- 补充验收：360、390、768、900、1180、1280、1440、1920px，9 个模板，共 72 组检查；没有页面溢出、导航碰撞或缺图；缺少钱包的错误反馈和显式切换示例模式通过。
