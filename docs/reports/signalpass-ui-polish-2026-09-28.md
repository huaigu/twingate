# SignalPass UI 细节优化记录

日期：2026-09-28。功能基线提交：ff340df。

本轮保留原有纸张拼贴、人物形象和页面结构，优化真实产品入口、操作文字、空状态和回执细节。使用用户指定的 supertoken-gpt-image-2 skill，通过 Sunburst 生成一张与现有风格相符的信封／卡片插画，已作为原生空状态中的装饰图接入。Hunyuan 运行时仍未配置。

## 已落地的修改

- **账户入口**：把登录条移出绝对定位、整体缩放的场景，修复桌面端与页头重叠。增加稳定的加载占位，压缩常态文案为身份与说明两层；手机端实测由 97–118px 收敛到 80px。
- **操作一致性**：统一关键按钮的无衬线字体、字号、边角、焦点、悬停和按下反馈。设置页手机按钮文字从 11px 提升到 14px；桌面缩放场景也保持实际操作尺寸。
- **空状态**：发现页、私密收件箱、无可用收件人和连接错误均给出明确下一步。新插画按 WebP 压缩为 32,456 字节，预留尺寸，使用空 alt；文字、按钮和交互仍由 HTML 实现。
- **回执**：统一阅读节奏和状态标签，使用等宽数字呈现金额，突出保证金，减轻外围边框，并改善长交易哈希的换行。
- **收件箱细节**：筛选结果为空时隐藏旧的详情，避免列表与详情显示不同状态。
